# תרגול מבחן — מערכות בינה מלאכותית מתקדמות

כלי תרגול ושינון ל-180 שאלות רב-ברירה מהמבחן לדוגמה בקורס
**"מערכות בינה מלאכותית מתקדמות: מבוא ל-LLMs, סוכנים וריבוי סוכנים"**, אוניברסיטת בר-אילן.

מפתח התשובות **מעוגן בחומרי הקורס** — לא בניחוש. לכל שאלה מוצמדים הסבר קצר, הפניה למקור, ודירוג ודאות.

## הפעלה

**[פתח את האתר](https://papadoc007.github.io/biu-llm-exam-practice/)** — או הורד את `index.html` והרץ מקומית.
אין שרת, אין התקנה, עובד אופליין. ההתקדמות נשמרת ב-localStorage של הדפדפן.

## מצבים

| מצב | מה הוא עושה |
|---|---|
| **תרגול** | שאלות מעורבבות עם משוב והסבר מיידיים. הדגימה משוקללת לפי תיבת Leitner — שאלות שטעית בהן חוזרות פי 5 יותר. זה מנוע השינון. |
| **סימולציית מבחן** | כל 180 השאלות, בלי הסברים, עם טיימר. בסוף: ציון, זמן, ורשימת השאלות שנפלת בהן. |
| **חזרה על טעויות** | רק שאלות שטעית בהן או שסימנת בדגל. |
| **סטטיסטיקה** | התקדמות כללית, פילוח דיוק לפי נושא, ורשימת השאלות הלא-מאומתות. |

מקשים: `1`-`4` לבחירת תשובה · `Enter` להבא · `f` לסימון · כפתור איפוס מנקה הכל.

|---|---|---|

השאלה היחידה ב-`low` היא **#41 (מודל 4P לממשל AI)**: המחרוזת "4P" אינה מופיעה באף אחד מחומרי הקורס.
התשובה שניתנה, `Policy, Process, People, Technology`, היא לפי המודל המקובל בתעשייה — ניחוש מושכל בלבד.

## עריכה

`questions.json` נבנה מ-`parts/p1..p6.json`. לשינוי תשובה — ערוך את קובץ ה-part ואז:

```bash
python build.py && python check.py
```

`check.py` נכשל אם חסרה שאלה, יש id כפול, אין בדיוק 4 מסיחים, או ש-`correct` מחוץ לטווח.

## קרדיט ומגבלות שימוש

השאלות והחומרים שעליהם מבוסס מפתח התשובות הם יצירתו של **ד"ר יורם סגל**, מרצה הקורס.
המאגר כאן נועד ללימוד עצמי של סטודנטים בקורס בלבד. חומרי הקורס עצמם (מצגות, חוברות, סיכומי הרצאות)
**אינם** כלולים בריפו הזה. האתר מסומן ב-`noindex` ואינו מיועד לאינדוקס במנועי חיפוש.

התשובות הן פרשנות שלי לחומר, לא מפתח רשמי. במקרה של סתירה — מה שנאמר בכיתה גובר.
